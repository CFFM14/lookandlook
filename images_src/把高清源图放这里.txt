把要重做的高清源图放在这个文件夹里（images_src/）。

【命名建议】文件名里包含下面的中文关键词即可，AI 会自动对应到游戏资源：
- 柚子 / 桃子 / 梨子 / 橘子 / 紫葡萄 / 红苹果 / 草莓 / 菠萝 / 西瓜 / 青苹果 / 青葡萄 / 香蕉
    → 对应 fruit_01 ~ fruit_12（12 张水果卡）
- 背景 / background（游戏内背景图） → bg_game
- 主菜单背景 / menu background       → bg_menu
- 提示                              → btn_hint（提示按钮）
- 打乱                              → btn_shuffle（打乱按钮）
- 炸弹                              → btn_bomb（炸弹按钮）
- 标题 / 水果（标题图）             → title_menu

【要求】
- 水果卡：尽量 500×500 以上、带透明背景的 PNG。
- 背景图：尽量 1080×1920 以上的高清图（横竖都可，AI 会按游戏尺寸裁剪/压缩）。
- 按钮/标题：尽量 500×500 以上、带透明背景的 PNG。

【之后】
放好后告诉 AI 一声（或直接说"放好了"），AI 会：
1. 按蔬菜卡同款"调色板量化 PNG"流程重生成；
2. 替换进 images/，保持主包 < 4MB；
3. 真机打包验证不超 4MB 限制。
（水果 12 张若你没单独发，AI 会用 Cocos 工程里已有的 500×500 高清源兜底。）
